# Sudoku Validator 🧩

A Python-based Sudoku Validator that checks whether a given 9×9 Sudoku board is valid.

## Features

- Validates all rows
- Validates all columns
- Validates 3×3 boxes
- Uses `0` for empty cells
- Displays whether the Sudoku is valid or invalid
- Handles invalid input

## Technologies Used

- Python
- Lists
- Sets
- Loops
- Functions

## How to Run

```bash
python sudoku_validator.py
